# Security status

SENRO is experimental and unaudited. The website simulates unsigned venue transactions and evaluates draft rules locally; it does not sign or broadcast. The guard is undeployed and the browser is not connected to it. Direct venue calls bypass its rules.

Do not commit wallet keys, generated deployment keypairs, private RPC endpoints or environment files. This repository contains no automatic deployment workflow. Review the actual deployment identity, upgrade authority, browser instruction assembly and independent security findings before enabling real trades.
