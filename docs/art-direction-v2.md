# SENRO background direction

The generated chrome sculpture and 3D icon atlas were removed from the website on November 10, 2026, following the requested Clock In background reference.

The site now uses an original procedural canvas background: a quiet dot lattice, a glow that follows a moving cursor with a short fading trail, and expanding click/tap pulses at the interaction point. Hover light fades after movement stops. On phones, touching triggers a pulse and the glow follows the finger during native scrolling, stays lit while held, and fades after release. The animation loop rests when all effects have faded. No external assets or source code from the reference site are used.

Motion can be paused. Reduced-motion preferences render a static frame, and animation suspends while the tab is hidden. Canvas pixel density and frame rate are capped. Product icons use the existing SVG system.
